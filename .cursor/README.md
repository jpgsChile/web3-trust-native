# `.cursor` — Configuración Oficial del Editor Constitucional

Este directorio convierte Cursor en el **editor oficial de la Constitución Web3 Trust-Native**.

No constituye autoridad normativa.

La autoridad reside exclusivamente en la Constitución (`constitution/`), no en esta carpeta.

## Responsabilidades

| Carpeta | Responsabilidad única |
|---------|----------------------|
| `rules/` | Deberes interpretativos del Agent |
| `hooks/` | Vigilancia mecánica |
| `commands/` | Rituales de trabajo constitucional |
| `skills/` | Playbooks bajo demanda |
| `agents/` | Subagentes de custodia |
| `references/` | Mapas estables sin autoridad normativa |

## Activación

- **Siempre:** `rules/core/*`
- **Al editar Libros:** `rules/constitution/*` + `rules/editorial/*`
- **Al editar metaespecificación:** `rules/meta/*` + editorial
- **Bajo demanda:** `rules/future/*`, `skills/`, `agents/`, `commands/`

## Principio rector

> Cursor custodia la representación del conocimiento constitucional.
> No legisla. No inventa. No contradice. No automatiza migraciones normativas.
