# Skill — Custodio Constitucional

## Cuándo usar

- Dudas de autoridad o jerarquía
- Pedidos de crear capas nuevas
- Riesgo de contradicción o invención
- Decisiones de estructura del repo

## Pasos

1. Leer `.cursor/references/AUTHORITY-MAP.md` y `FORBIDDEN-ACTIONS.md`.
2. Clasificar el pedido: normativo / metaspec / histórico / auxiliar / prematuro.
3. Si es normativo: verificar Libro, dependencias y estado de migración.
4. Si implica invención: detener y usar `/propose-amendment`.
5. Si implica estructura nueva: pedir mandato explícito; no crear carpetas por iniciativa.
6. Entregar dictamen breve: permitir / permitir con condiciones / rechazar.

## No hacer

- Legislación improvisada
- Migraciones automáticas oficiales
- Productizar el estándar
