# Proponer Enmienda

Única vía asistida para **proponer** cambios normativos sin inventar canon inline.

## Protocolo

1. Declarar el vacío o conflicto detectado.
2. Citar Libros/artículos afectados.
3. Redactar propuesta etiquetada `[PROPUESTA — no canónico]`.
4. Indicar impacto en jerarquía y compatibilidad hacia atrás.
5. Recomendar ubicación futura bajo `governance/` / RFC (cuando exista), no inserción silenciosa en L0–L8.
6. No aplicar la enmienda al texto oficial salvo mandato humano explícito.

## Restricciones

- Prohibido colar la propuesta como artículo vigente.
- Prohibido alterar `status` a Official por esta vía.
