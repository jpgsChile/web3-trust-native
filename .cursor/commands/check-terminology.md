# Verificar Terminología

## Protocolo

1. Usar `.cursor/references/EDITORIAL-CANON.md` como base.
2. Escanear Libros y metaspec en busca de:
   - descripción de WTN como framework/plataforma/SaaS
   - sinónimos peligrosos (UNE≈microservicio, Materialización≈frontend, etc.)
   - términos `[PROPUESTA]` sin marcar
3. Reportar ocurrencias con archivo y fragmento.
4. No reescribir en masa sin mandato.

## Salida

Inventario de desviaciones + recomendaciones de forma canónica.
