# Revisar Libro

Revisión constitucional de un `BOOK.md` migrado.

## Entrada requerida

- Libro (`L0`…`L8` o `L3-DA`)

## Protocolo

1. Comparar estructura y afirmaciones clave contra la fuente histórica del Libro cuando sea posible.
2. Verificar estilo con `.cursor/references/EDITORIAL-CANON.md`.
3. Verificar jerarquía: no contradice niveles superiores (`dependsOn`).
4. Verificar referencias según `.cursor/references/CROSSREF-POLICY.md`.
5. Detectar términos no canónicos.
6. Emitir veredicto: `aprobable` / `aprobable con cambios` / `rechazar`.

## Restricciones

- No “arreglar” contradicciones reescribiendo L0 u otros superiores sin mandato.
- No inventar contenido faltante para cerrar huecos.
